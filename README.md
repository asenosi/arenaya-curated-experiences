# arenaya-curated-gifts

Build a responsive, elegant website with tasteful animations for “Arenaya Corporate Gifting”. Goal: position Arenaya as a turnkey partner for corporate gifting, branded apparel, and industry-specific solutions (real estate, automotive dealerships, construction/mining, office launch kits). Tone: premium, warm, trustworthy, design-led.

PRIMARY INFO
- Brand name: Arenaya Corporate Gifting
- Tagline: Curated Gifts & Branded Experiences
- Short value line: Thoughtful. Premium. On time.
- Locations served: South Africa & Eswatini (cross-border capable)
- Primary CTAs: “Request a Quote”, “View Catalogue (PDF)”, “WhatsApp Us”
- Contact: Email: hello@arenaya.co.za (placeholder); Phone/WhatsApp: +27 00 000 0000 (placeholder)
- Socials: placeholders

STYLE GUIDE
- Color palette:
  * Sand/Beige #F3EEE7 (backgrounds)
  * Warm Ivory #FFFDF9 (cards/sections)
  * Charcoal #1E1E1E (headings/body on light)
  * Deep Navy #0E2A3A (accents, buttons alt)
  * Gold Accent #C8A85C (subtle lines/icons/hover)
  * Terracotta #C86F4A (small highlight tags)
- Typography:
  * Headings: Playfair Display (fallback: "Times New Roman", serif)
  * Body/UI: Lato (fallback: Arial, sans-serif)
  * Numbers/UI counters: Lato SemiBold
- Imagery: luxurious lifestyle shots of packaging, ribbons, textures; industry context images (keys/house handover, dealership handovers, braai/outdoor, office launch décor); product closeups (diaries, pens, apparel embroidery)
- Icon style: thin-line, minimalist
- Spacing: generous white space; 8px grid; section padding 80–120px desktop, 48–64px mobile

ANIMATION DIRECTION (tasteful, high-performance)
- On scroll: 10–20% fade-up with slight Y translate; stagger children by 60–100ms
- Hero headline: gentle letter-spacing reveal (300ms)
- Buttons: subtle scale(1.02) + shadow on hover
- Cards: elevate on hover (shadow + 2px translateY)
- Page transitions: fast fade (150–200ms) when navigating
- Reduce motion for prefers-reduced-motion users

RESPONSIVENESS
- Breakpoints: 0–599 (mobile), 600–1023 (tablet), 1024–1439 (laptop), 1440+ (desktop)
- Navigation:
  * Desktop: top bar with logo left, menu right
  * Mobile: sticky header, hamburger → full-height overlay menu
- Grids auto-reflow to 1-column on mobile; ensure tappable targets ≥44px
